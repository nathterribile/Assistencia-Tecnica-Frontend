
# MyAssist frontend 

Frontend of an web app for an technical assistance enterprise. 


## Labels

- [JS](https://js.org/ "JavaScript")
- [Node Js](https://nodejs.org/pt "Node Js")
- [Bootstrap](https://getbootstrap.com/ "Bootstrap")


## Stack utilizada

**Front-end:** JavaScript


## Functionalities

- User generation for new employee
- Employee login to register service order
- User deletion for old employee
- Registration of new service order by employee
- Change of registered service order by employee
- Search for all registered service orders by employee
- Check service order registered with ID by employee
- Schedule service for smartphone, tablet or notebook by clients

## Run

To run locally the webpage run the command

```cmd
  npm start
```
It will start on port: 8080. To not get in conflict with backend project run, it's necessary to start the frontend project after the backend or run the command 

```cmd
  set PORT=1200
```

For change the port of the frontend project running to 1200.
